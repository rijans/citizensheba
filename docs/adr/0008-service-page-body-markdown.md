# Service Page body Markdown (EN + BN)

Service hop pages needed richer human- and SEO-friendly copy without bloating Instant Directory cards or Meta Descriptions. We keep short `description` / `description_bn` for cards and SERP, and require longer Markdown `body` / `body_bn` rendered on the Service Page after the Outbound CTA (**BN first, then EN**, with an equal-spaced divider). Body copy describes the government Service only — no CitizenSheba hop-disclaimer paragraphs (Non-Official stance stays in site chrome). We rejected expanding the short description fields in place and rejected full Guide-length essays (still hop-first; Trap #9).

**Living structure:** [`docs/guides/service-page.md`](../guides/service-page.md) — update that guide when hop section order or body placement changes.
