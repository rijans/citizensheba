# Service Page body Markdown (EN + BN)

Service hop pages needed richer human- and SEO-friendly copy without bloating Instant Directory cards or Meta Descriptions. We keep short `description` / `description_bn` for cards and SERP, and require longer Markdown `body` / `body_bn` rendered on the Service Page after the Outbound CTA (EN first, then BN). We rejected expanding the short description fields in place and rejected full Guide-length essays (still hop-first; Trap #9).
