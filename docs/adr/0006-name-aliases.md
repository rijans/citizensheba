# Name Aliases for search and former labels

Citizens search with alternate, informal, former, and romanized names that are not the curated Display Name. Every Service **must** include typed `aliases` (`name`, `lang`, `kind`) with at least two entries covering both `en` and `bn`. Instant Directory scores all alias names; the Service Page shows a muted “Formerly …” line only for `kind: former`. We rejected stuffing these into `tags` alone and rejected changing Service Slugs on rename. Schema + `content-integrity.test.ts` enforce coverage so new Services cannot ship without aliases. Display Name casing remains ADR-0005; search ranking details are ADR-0007.
