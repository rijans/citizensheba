# Agent discovery and AI usage signals

We want agents to understand and cite the Directory, but we do not want our content used as AI training data by default. We will ship a build-generated `/llms.txt` for curated agent discovery, enforce preferences with known AI crawler rules in `robots.txt` (`GPTBot` Allow for citation/input; `Google-Extended` Disallow for training), and mirror the same policy in advisory `/.well-known/ai.txt` plus a commented `Content-Signal` note in `robots.txt`. We rejected treating `ai.txt` as the sole control plane because it is not a ratified, widely enforced standard. We also rejected an active `Content-Signal:` robots directive as the primary plane because PageSpeed / some validators mark it as an unknown directive (Cloudflare notes GSC may do the same without crawl impact); comments + crawler Allow/Disallow keep SEO validators green while preserving intent.
