# Service card description clamp (2 lines) + length floor

Instant Directory and related Service cards were uneven in a row when EN `description` wrapped to different heights (previously clamped at 3 lines). We **clamp the card description to 2 lines** with ellipsis on the shared `.service-card`, **pin the official domain to the card bottom** (`margin-top: auto` in the flex column; grid items stretch so cards share row height), and **require EN `description` ≥ 90 characters** so every card has enough copy to fill about two lines at typical desktop card width. We rejected a forced 2-line `min-height` slot (extra empty padding on short copy), Home-only CSS (diverges from the shared card), and a BN description floor on cards (cards render EN description only in v1).
