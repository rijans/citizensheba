# Display Name casing vs official sites

Official Bangladesh portals often publish inconsistent or nonstandard English casing (e.g. homepage `a2i`). CitizenSheba uses a curated **Display Name** in Service `title` and every English mention in that Service’s content; Outbound Link hostnames stay exact. Clear cases follow house rules (ALL CAPS acronyms, lowercase `e-` prefixes, preserve camelCase brands like myGov); stylized or conflicting brands escalate to a human. Living cheat sheet: [`docs/guides/display-names.md`](../guides/display-names.md) (update when a brand is decided). Name Aliases (synonyms / former names) will use a **dedicated content field**, not `tags` — shape and ship timing still open in that guide. We rejected always mirroring the live homepage (citizens get a messy catalog) and rejected asking before every casing tweak (too slow for obvious acronyms).
