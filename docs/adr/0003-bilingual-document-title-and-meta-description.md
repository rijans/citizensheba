# Bilingual Document Title and Meta Description

SERP copy must surface Bengali first while the Mixed UI keeps English-first visible H1s. We generate Document Titles as `বাংলা — English | CitizenSheba Bangladesh` and Meta Descriptions as a Bengali sentence followed by an English sentence. Composition uses content fields (`title_bn`/`title`, optional Service `serp_title_bn`/`serp_title` when Display Names are too short for SERP, category `name_bn`/`name`, `description_bn`/`description`, plus BN/EN site constants on static pages). Brand postfix is `SITE_BRAND_SERP` (`CitizenSheba Bangladesh`), not the short `SITE_NAME` alone. We rejected free-form `meta_title` / `meta_description` overrides and rejected flipping on-page H1 order to match SERP order.
